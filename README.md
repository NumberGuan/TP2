# Productivity Tips App

Una aplicación web moderna para descubrir y votar por consejos de productividad. Construida con React, Vite y framer-motion para animaciones fluidas y una experiencia de usuario de alta calidad.

## Requisitos previos

Antes de comenzar, asegúrate de tener instalado en tu sistema:
- [Node.js](https://nodejs.org/) (versión 18 o superior recomendada)
- npm (normalmente se instala junto con Node.js)

## Instalación y ejecución local

Sigue estos pasos para descargar y ejecutar el proyecto en tu máquina local:

1. **Clonar o descargar el repositorio**
   Si usas Git, puedes clonar el repositorio:
   ```bash
   git clone <url-del-repositorio>
   ```
   *(Si descargaste el archivo ZIP del proyecto, simplemente descomprímelo y abre la carpeta principal).*

2. **Navegar a la carpeta del proyecto**
   Abre tu terminal o consola de comandos y dirígete al directorio donde se encuentra el proyecto (donde está el archivo `package.json`):
   ```bash
   cd tp2
   ```

3. **Instalar las dependencias**
   Ejecuta el siguiente comando para instalar todas las librerías necesarias para que funcione la aplicación:
   ```bash
   npm install
   ```

4. **Iniciar el servidor de desarrollo**
   Una vez instaladas las dependencias, arranca la aplicación ejecutando:
   ```bash
   npm run dev
   ```

5. **Abrir la aplicación en tu navegador**
   En la terminal aparecerá un mensaje indicando que el servidor está corriendo (generalmente en `http://localhost:5173/`). Copia esa URL o haz clic en ella para abrir el proyecto en tu navegador web.

## Tecnologías principales
- **React** - Biblioteca para la interfaz de usuario.
- **Vite** - Herramienta de compilación rápida.
- **Framer Motion** - Para animaciones y transiciones fluidas.
- **CSS Vanilla** - Diseño Modern Dark SaaS.
